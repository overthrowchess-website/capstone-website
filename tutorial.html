Get the app

From install to
first analysis

A quick-start guide for Demo Day reviewers and first-time users. Follow these steps to install the app, play a match, and explore what's currently available.

Install TestFlight from the App Store, then tap "Install via TestFlight" on the Download page. Follow the prompts to install Overthrow Chess on your iPhone. On first launch, allow network access so matchmaking and account services can connect.
Sign up using the in-app authentication flow and choose a player name. This name is used in matches, stats, and leaderboard views. If you already have credentials from a previous session, use sign-in instead.
From the lobby, choose Play Online for matchmaking or Play AI for a bot game. Time controls are grouped into bullet, blitz, and rapid options. Tap Play to enter the queue. When paired, the board opens automatically. Daily time controls are visible but currently marked as coming soon.
Open the Friends tab to send friend requests. Once connected, you can challenge a friend directly instead of using public matchmaking. This is useful for reviewers testing with a teammate. In-game text chat is available during matches, and voice chat controls appear when supported by your build and device.
Play a full game using drag or tap controls. After the game ends, the result overlay appears. From there, open the review screen to replay moves step-by-step with analysis data overlaid on the board. This feature is available for completed online games.
Visit the Stats tab to see recent matches, rating trends, and mode-specific filters. Leaderboard cards appear for modes where you have completed games. Then try Puzzle Rush or Random Puzzle for tactics training. Some additional puzzle flows are present but marked under construction.

Current Limitations

  • Daily time controls are displayed in the UI but marked as coming soon and are not yet playable.
  • Most alternate game modes (4-player, fog of war, etc.) are shown on the Game Modes screen but labeled coming soon.
  • Several puzzle submodes are present but marked under construction.
  • Voice chat signaling infrastructure is in place, but availability depends on device and build and is not guaranteed on all devices.
  • If matchmaking appears slow, verify your network connection and retry queue entry.
  • If TestFlight shows the build as unavailable, try reinstalling via the link on the Download page.
