System Requirements

What you need to test our app.

📱

Physical Device

iOS 16.0 or newer. Install TestFlight from the App Store. For Android, download the APK.

🌐

Internet Connection

Required for account login, online matchmaking, and synchronized multiplayer gameplay.

🎧

Optional: Microphone

Enable mic permissions only if testing voice controls. Availability depends on device and build support.

Installation Steps

  • Install TestFlight from the App Store if you don't have it
  • Tap "Install via TestFlight" above to open the install page
  • Launch the app, create an account or sign in
  • Play a match from the main queue to verify connectivity
  • Open post-game analysis from the result screen
